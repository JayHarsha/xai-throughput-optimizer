====================================================================
  HYPOTHESIS TESTS
====================================================================

  Research Narrative
  ──────────────────
  The three tests form a sequential chain of evidence designed to answer
  the central research question: Can asynchronous decoupling make XAI
  computationally transparent to the user under concurrent load?

  Step 1 establishes that the problem is real.
  Step 2 validates that the proposed solution addresses it.
  Step 3 tests whether the solution achieves the ideal outcome.


  Step 1  (Establish the problem): Synchronous XAI inflates tail latency beyond the no-XAI baseline
  Research question : Is the latency problem caused by XAI, or by the API infrastructure?
  Test              : Mann-Whitney U [greater],  Synch XAI  vs  No XAI
  U statistic       : 162.0
  p-value           : 0.0208   (< 0.05 — significant)
  Effect size       : r = 0.44  (medium effect)
  Median Synch XAI         :   12,000 ms
  Median No XAI            :       58 ms
  Verdict           : SUPPORTED  ✓

  Step 2  (Validate the solution): Async pipeline significantly reduces tail latency vs synchronous XAI
  Research question : Does moving XAI off the request path actually fix the problem?
  Test              : Mann-Whitney U [greater],  Synch XAI  vs  Asynch XAI
  U statistic       : 135.0
  p-value           : 0.1792   (> 0.05 — not significant)
  Effect size       : r = 0.2  (small effect)
  Median Synch XAI         :   12,000 ms
  Median Asynch XAI        :   21,000 ms
  Verdict           : NOT SUPPORTED  ✗

  Step 3  (Test the ideal outcome): Async Tier-1 perceived latency is statistically equivalent to no-XAI baseline
  Research question : Is async so fast that XAI is effectively free from the user's perspective?
  Test              : Mann-Whitney U [two-sided],  Asynch XAI  vs  No XAI
  U statistic       : 159.5
  p-value           : 0.0462   (< 0.05 — significant)
  Effect size       : r = 0.418  (medium effect)
  Median Asynch XAI        :   21,000 ms
  Median No XAI            :       58 ms
  Verdict           : NOT SUPPORTED  (p < 0.05, distributions differ)

====================================================================
  INTERPRETATION
====================================================================

  Step 1 — Problem established:
  CONFIRMED
  Synch XAI adds 207x median
  latency overhead vs No XAI. The bottleneck is XAI computation,
  not API infrastructure. p = 0.0208, r = 0.44 (medium effect).

  Step 2 — Solution validated:
  NOT CONFIRMED
  Asynch XAI reduces median p95 from 12,000 ms (Synch XAI) to
  21,000 ms — a -75% reduction.
  Asynchronous decoupling via Redis/Celery is a statistically validated
  architectural fix. p = 0.1792, r = 0.2 (small effect).

  Step 3 — Ideal outcome:
  NOT ACHIEVED (scope limitation)
  Tier-1 SHAP runs synchronously before returning, adding measurable overhead under high concurrency (25+ users). Asynch XAI reduces tail latency by ~-75% vs Synch XAI (Step 2 confirmed) but does not fully reach the No XAI floor. p = 0.0462. Future work: precompute or cache Tier-1 explanations to close this gap.
